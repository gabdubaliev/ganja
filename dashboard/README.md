# Продажи и склад — дашборд для CloudShop

Одна страница, которую можно держать открытой на главном экране:

- **Период**: сегодня, 7 дней, 30 дней, 90 дней, год. Каждый показатель сравнивается с таким же прошлым периодом.
- **Главные цифры**: выручка, прибыль, маржа, число чеков, средний чек.
- **График**: выручка по часам, дням или месяцам, разделённая на прибыль и себестоимость.
- **Хиты**: топ-8 товаров по количеству, по выручке и по прибыли, со сдвигом места относительно прошлого периода.
- **Товары и остатки**: таблица со всеми товарами. Показывает, на сколько дней хватит остатка, и помечает товары, которых нет в наличии, которые заканчиваются (меньше 7 дней) или не продаются. Можно сортировать по любому столбцу и искать по названию.

Данные обновляются каждые 5 минут. Без токена CloudShop страница показывает выдуманные демо-данные.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 18 или новее. Больше ничего ставить не нужно.

```bash
cd dashboard
cp .env.example .env     # впишите CLOUDSHOP_TOKEN
npm start
```

Откройте в браузере http://localhost:3000.

Чтобы открыть дашборд с другого устройства в той же сети (телевизор, планшет у кассы), задайте в `.env` `HOST=0.0.0.0` и откройте `http://<адрес компьютера>:3000`. Тогда данные о продажах увидит любой в этой сети.

## Подключение CloudShop

1. Получите API-токен в настройках CloudShop (раздел про интеграции / API, документация: https://connect-api.cloudshop.ru).
2. Впишите его в `.env` в строку `CLOUDSHOP_TOKEN=`. Токен хранится только на вашем компьютере, браузер его не видит.
3. Проверьте связь:

   ```bash
   npm run check
   ```

   Команда покажет, что CloudShop отдаёт по товарам и продажам, и как программа это поняла.

**Важно.** При разработке у программы не было доступа к документации API CloudShop, поэтому пути (`/catalog`, `/sales`) и названия полей выбраны по типичным вариантам. Если `npm run check` показывает ошибку или в разобранном товаре пустые название, цена или остаток:

- поправьте пути в `.env` (`CLOUDSHOP_PRODUCTS_PATH`, `CLOUDSHOP_SALES_PATH`, `CLOUDSHOP_STOCK_PATH`) по документации;
- или поправьте списки полей в функциях `normalizeProduct` и `normalizeSale` в `cloudshop.js`.

Прибыль считается как выручка минус себестоимость. Себестоимость берётся из строки чека, а если её там нет, то из карточки товара. Если в CloudShop не заполнена себестоимость, прибыль будет равна выручке.

## Файлы

- `server.js` — сервер: отдаёт страницу и данные, кэширует ответы CloudShop на минуту.
- `cloudshop.js` — запросы к API CloudShop и приведение данных к общему виду.
- `public/index.html` — сам дашборд и генератор демо-данных.
